# Sales Data Analytics Dashboard

A Python-based end-to-end data analytics project that cleans a raw Excel sales dataset, performs exploratory data analysis, generates business insights, and produces a fully interactive browser-based analytics dashboard.

This project was developed as part of the **IBM SkillsBuild Data Analytics with AI Academic Internship Program**, conducted by **BharatCares in association with AICTE**.

---

## 📌 Project Overview

The project demonstrates a complete data analytics workflow starting from a raw Excel dataset containing intentional data-quality issues.

The workflow includes:

* Loading the raw Excel dataset
* Inspecting the data and identifying quality issues
* Cleaning and standardising the dataset
* Removing duplicate and invalid records
* Performing exploratory data analysis
* Analysing sales performance by category, region, product, and time
* Generating business insights
* Creating an interactive browser-based analytics dashboard

The final cleaned dataset contains **1,891 rows** after processing the original **2,000-row** dataset.

## 📊 Dataset

The project uses an Excel sales dataset containing **2,000 raw records** and **9 columns**.

### Dataset File

[Open / View Dataset – excelsheet.xlsx](./excelsheet.xlsx)

### Dataset Columns

| Column        | Type    | Description                       |
| ------------- | ------- | --------------------------------- |
| `Order_ID`    | Integer | Unique order identifier           |
| `Order_Date`  | Date    | Date the order was placed         |
| `Customer_ID` | String  | Customer identifier               |
| `Product`     | String  | Product name                      |
| `Category`    | String  | Product category                  |
| `Region`      | String  | Sales region/city                 |
| `Quantity`    | Integer | Number of units ordered           |
| `Revenue`     | Float   | Revenue generated by the order    |
| `Profit`      | Float   | Net profit generated by the order |

## 🧹 Data Cleaning

The raw dataset contained several intentional data-quality problems. The following cleaning operations were performed:

| Step | Operation                                                         |
| ---- | ----------------------------------------------------------------- |
| 1    | Dropped unnamed / empty columns                                   |
| 2    | Removed exact duplicate rows                                      |
| 3    | Converted `Order_ID` from float to integer                        |
| 4    | Parsed and validated `Order_Date` values                          |
| 5    | Filled missing `Customer_ID` values with `UNKNOWN`                |
| 6    | Filled missing `Product` values with `UNKNOWN`                    |
| 7    | Standardised `Category` values using title case                   |
| 8    | Standardised `Region` values using title case                     |
| 9    | Removed rows with missing or non-positive `Quantity`              |
| 10   | Cleaned `Revenue` by removing currency symbols, `INR`, and commas |
| 11   | Filled missing `Profit` values with `0`                           |
| 12   | Added the `Sales` column                                          |
| 13   | Ordered and exported the final cleaned dataset                    |

### Cleaning Result

```text
Raw records      : 2,000
Cleaned records  : 1,891
Records removed  : 109
```

The cleaning process is also documented inside the Jupyter Notebook and the dashboard's **Cleaning** section.

## 💡 Key Insights

Based on the completed analysis and dashboard:

* **Electronics** is the leading revenue-generating product category.
* **Pune** is the highest-revenue region in the analysed dataset.
* Revenue and profit vary considerably across the different months.
* The dashboard reports an overall **profit margin of approximately 16.1%**.
* The analysis provides category-, region-, product-, and time-based views of sales performance.
* Data cleaning removed invalid, duplicate, and unusable records before analysis.

## 🚀 How to Run

### Step 1 — Clone or download the project

Download the complete project folder containing the required files.

### Step 2 — Install dependencies

Open a terminal inside the project folder and run:

```bash
pip install -r requirements.txt
```

### Step 3 — Run the Jupyter Notebook

Open:

```text
Chitesh_SalesDataAnalytics.ipynb
```

Run the notebook cells from top to bottom.

### Step 4 — Clean the dataset

Run:

```bash
python data_cleaner.py
```

This processes `excelsheet.xlsx` and generates:

```text
cleaned_data.csv
```

### Step 5 — Generate the dashboard

Run:

```bash
python dashboard.py
```

This generates:

```text
dashboard.html
```

The generated HTML dashboard can then be opened directly in a web browser.
